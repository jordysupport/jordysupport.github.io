# Give your agent a smaller job

Issue #002 · DRAFT for review. Not published.

## One thing worth doing

Try an agent on a task you can check in a few minutes.

Make a practice folder with `input` and `output` folders inside it. Put copies of two or three short, non-sensitive notes in `input`. Keep the originals elsewhere.

Give the agent this job:

> Read only the notes in input. Write a short summary with the main points, decisions, and unanswered questions. Name the source file for each decision. If the notes conflict, say so.
>
> First list the files and explain your plan. Wait for approval before writing output/summary.md. Leave the input files unchanged. Do not use the web or other apps.

Review the plan, then let it write the draft. Compare the summary with the notes. Did it invent a decision, miss a question, or fill in a date that wasn't there?

If it did, point to the sentence and the source note. Ask for that correction before giving it a bigger job.

Our [first agent exercise](https://jordysupport.com/getting-started/first-agent/) walks through the setup and checks.

## Worth knowing

A written instruction tells the agent what you want. Permission settings control what it can access. Check both before handing it files or connecting an account.

See [Keeping it safe](https://jordysupport.com/fundamentals/safety-permissions/) and the [workflow brief](https://jordysupport.com/automation/workflow-blueprint/) before you put a task on a schedule.
