# Ask it twice

Issue #001 · August 2026

## One thing worth doing

When an answer matters, try asking in a fresh chat. Differences can reveal an assumption or a detail you need to investigate. Ask each chat to explain which sources support the answer, then open those sources yourself.

Agreement is useful to compare, but it isn't proof. Two chats can repeat the same mistaken claim, especially when they use similar training or the same source. They can also give different answers because your question leaves something open.

Try this follow-up:

```text
Which parts of this answer are directly supported by a source?
Give me the source and the relevant passage or section.
Separate assumptions from facts, and say what would change the answer.
```

Check that the source exists, covers the claim, and applies to your situation. For current facts, check its date too. See [why AI makes things up](../fundamentals/why-ai-makes-things-up.md) for more ways to review an answer.
