# Prompt library

Replace the `[brackets]` with your details. These examples give the AI a useful brief and something you can check. If your app can use tools, add the permissions that fit the job.

## Summarize anything

```text title="Copy this"
Summarize the material below for [audience] in under [150] words.
Put the decisions and next steps first. Preserve important
qualifications and flag anything unclear or missing.
Use only this material.

[paste material]
```

## Improve my draft { #improve-my-draft-without-rewriting-my-voice }

```text title="Copy this"
Edit the draft below for grammar, clarity, and unnecessary words.
Keep my meaning and the parts that sound like me. Do not add
claims or promises. Show the revised draft, then briefly explain
any changes that affect the meaning.

[paste draft]
```

## Compare options

```text title="Copy this"
Compare [option A] and [option B] for [situation].
My priorities are [priorities], and my constraints are [limits].
Check current official information where needed. Show the
differences that affect my choice, link the sources, and explain
your recommendation. Flag anything you couldn't verify.
```

## Explain something to me

```text title="Copy this"
Explain [topic] to someone who understands [related topic]
but is new to this. Use a concrete example. Define unfamiliar
terms as they come up, and explain any limitation that matters
for [what I want to do].
```

## Turn chaos into a plan

```text title="Copy this"
Turn the notes below into a practical plan. Separate decisions,
next actions, and open questions. Preserve stated deadlines.
Don't invent owners or commitments. Ask if a missing detail
would change the first action.

[paste notes]
```

## Write a first draft

```text title="Copy this"
Draft a [email / post / page] about [topic] for [audience].
Aim for [length] and use [tone or a writing example].
Use only the facts below. Leave a clear placeholder where a
necessary fact is missing. Do not send or publish the draft.

Facts: [paste facts]
```

## Check work { #check-work-yours-or-the-ais }

```text title="Copy this"
Review the text below. Identify unsupported claims, conflicting
details, unclear wording, and promises we may not intend to make.
Quote the passage at issue and explain the problem.
Do not rewrite it yet.

[paste text]
```

## Give an agent a bounded job

```text title="Copy this"
Use [source folder] to prepare [deliverable] in [output folder].
Read the relevant files and use [template or requirements].
You may create the deliverable, but do not change the source
files, send messages, or publish anything.
Check [specific facts, totals, or links] before you finish.
Show me the result and list any missing inputs.
```
